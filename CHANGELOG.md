# Changelog

## 0.6.6 — 2026-11-01

First GitHub source snapshot of Starcore Assistant. This snapshot includes:

- A native macOS host with local Qwen3 ASR, configurable assistant name and wake phrase, and short continuous conversations.
- Yunqiao chat, optional DeepSeek speech polishing, and Fish Audio or macOS speech playback.
- Encrypted local credentials, preferences, and conversation history.
- Codex original-chat handoff and WeChat turn-completion notifications.
- A fixed-camera animated scene, project picker, and native app icon assets.
- The current-project context fix: local project queries and fresh selected-project metadata in chat requests.

Source checks cover 57 automated tests. Real microphone, paid service, WeChat delivery, and Codex version compatibility require separate local verification. iPhone and speaker integration are planned.
