# 0.5 三维动效修正

用户继续沿用已确认的全屏参考图，指出先前静态底图叠加呼吸效果缺乏真实的放大缩小。本次按该明确反馈修正已确认设计，不重新要求确认视觉方向。

环境背景和核心分离：imagegen 从原背景移除中心大球体，保留两侧空间、地面和光线；球体使用纹理材质的真实球面，轨道、刻度、弧段、粒子、光丝为 WebGL 三维几何。图像材质仅提供表面细节，不包含已画好的外轨道。

使用 Three.js 透视相机在全景和近景之间连续移动；前景与后景投影比例不同。核心可点击或滚轮缩放，顶部提供明确的查看核心/回到全景按钮。轨道以不同轴和不同速度运行，前后结构具有深度，背景图和 DOM 控件不缩放。

语音输入使用已有真实 RMS；Fish 播放增加原生 AVAudioPlayer 电平采样，通过独立 outputLevel 事件驱动。Mac 系统声音没有伪造电平，保持说话状态动效。减少动态关闭自动运动和电平驱动的相机运动，手动视角切换仍可使用。不可用的 WebGL 环境显示明确的静态备用状态。

本次保留云桥模型、可选 DeepSeek、Fish 音色、加密库和任务投递。只更新客户端与视觉资源，不重启 Codex 或微信后台服务。
