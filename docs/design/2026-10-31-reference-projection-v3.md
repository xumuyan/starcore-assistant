# 按原设计图校准动态样片

用户已选定 1672 × 941 的原始设计图，并要求继续做到相同外观；沿用已经授权的独立样片范围。

此前的程序化金属、空心轨道与白色核心改变了原图的材质语言。本轮复用原始无文字场景作为投影材质，按图中球壳、核心、底盘、星球分配到独立网格。保留实际几何、固定正交相机、局部形变、各层不同转速和可查看的结构线框。不能把整张参考图当成会缩放的背景，也不能将这种基于单视图的投影渲染描述成完整的任意视角三维复建。

首页恢复原图的品牌、时间、状态、正文、项目和最近对话布局。调试控制收进设置面板，参考图作为显式对照模式。独立样片不读取麦克风、调用模型或写入聊天记录。

验收：同尺寸比较静态首帧；连续帧验证分层运动和恒定全局比例；暂停冻结；线框继续运行；检查浏览器日志。保持原 Mac 客户端不变。本轮只修改 prototype 目录和相应测试、设计与 QA 证据。
