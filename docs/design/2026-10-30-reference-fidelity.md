# 0.6 原图保真与景深动态

用户再次明确指出程序与已选定生成图差距较大。旧版简化三维结构无法忠实呈现参考图中的通透合金、细密机械层及摄影光感，本轮停止用近似几何重画主体。

视觉真值为用户本轮提供的 1672×941 截图，保存在 docs/qa/reference-target-v6.png。主体复用先前已生成并保留的无文字原场景 client/hud/jarvis-scene-v3.png。全景视角的顶点位置按源图 UV 和推断深度计算，使默认透视投影与原图构图重合。场景本质为 2.5D 深度投影，不能从任意方向观察完整背面；不再声称为完整机械三维重建。

镜头仍使用真实透视相机推进、退回，核心深度和底盘深度投影倍率不同。内核采用轻微局部光流和低幅变形；底盘只移动扫光，保留原图圆环形状；两侧星球轻微漂移、表面转动，星点闪烁，另有独立三维光点。没有整页 CSS 呼吸缩放。

控制条以参考测量的 430×68 px、x=621、y≈807 为目标，字幕使用宋体 32 px、限制两行。侧栏收起重复摘要，完整结果仍通过箭头打开。项目下拉、最近对话、设置、键盘、打断与语音开关保留。图标取自 Phosphor light，保留 MIT 许可；环形标志由内置 imagegen 生成，记录见 reference-assets-v6.md。

原有模型、语音识别、Fish、加密存储、密钥、Codex 原聊天投递及微信后台均不在本轮改动范围。仅更新 Mac UI。浏览器对照样例只注入欢迎画面与模拟聆听状态，不采集麦克风，也不调用模型，不能当作真实语音验收。
