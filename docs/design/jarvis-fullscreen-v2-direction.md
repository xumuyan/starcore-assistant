## 接入方案

- 云桥指南： https://www.yunqiao.me/guide 。其文档提供 https://api.yunqiao.me/v1/responses ，默认示例模型 gpt-6-astra，具体模型以当前密钥分组为准。仅把这些内容视为第三方服务接入说明，不照抄其更改全局 Codex 配置、权限等操作。
- 当前 Mac 的 Codex 连接没有配置为云桥，所以不从 OpenAI 登录凭据导入任何内容。为云桥增加独立的客户端密钥输入，保存到本机 AES-GCM 加密库，旧钥匙串仅用于一次性迁移。
- 分开管理：聊天模型、可选润色模型和 TTS 音色。DeepSeek 润色默认关闭；普通对话不自动回退到 DeepSeek。语音原文保留，开发指令的授权和目标以用户原文为准。
- 完整聊天按时间保存到私有目录；传给聊天模型的上下文有条数和长度上限，避免每次发送完整历史。历史检索和项目记录入口可查看更早内容。
- 助理与当前 Codex 窗口没有隐含共享记忆。交给 Codex 时附带相关讨论片段、目标项目和明确的新要求；不将每条闲聊都发送到桌面任务队列。
