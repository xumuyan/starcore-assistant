# Tauri 2 + Rust 桌面架构迁移决策

状态：用户已确认采用 Tauri 2 + Rust，未来需要适配 Windows；仅完成技术选型与迁移规划，尚未引入 Tauri 依赖、创建壳工程或修改运行架构。SC-20261112-004；SC-20261112-005 新增独立 React 原组件预览与离线构建，未接入壳。

## 目标与现状

- 目标架构：Tauri 2 桌面壳 + Rust 业务核心 + 本地 HTML/CSS/JavaScript 视觉层。新隔离视觉层采用 React 以直接引用 Libraries.dev 原组件，现有前端代码仍允许复用。
- macOS 使用系统 WKWebView，Windows 使用 WebView2；相同页面需分别验证字体、透明背景、Canvas/WebGL、动画性能和缩放，不承诺跨平台逐像素自动一致。
- macOS 先迁移和验收，Windows 从架构阶段纳入约束，后续独立完成构建和真机验收；采用 Tauri 并不等于 Windows 客户端已经可用。
- 当前默认仍是 Swift/AppKit 客户端 + Node.js 服务；现有 Rust 宿主仅部分能力对齐，包含 Unix 专用实现，不能视作已跨平台。
- 旧客户端、构建入口、用户配置、凭据和加密历史数据保持不变，新壳旁路开发；不因本次选型自动替换已安装应用。

## 分层与平台适配

| 层 | 共享职责 | 平台差异与验收 |
| --- | --- | --- |
| 本地视觉层 | voice-ring / beam / voice / orbs、历史记录和设置；完全照参考站 | WKWebView 与 WebView2 分别视觉对照；效果离线打包，先核查许可 |
| Tauri 2 壳 | 窗口生命周期、托盘入口、受限 IPC 与状态事件 | macOS 菜单栏 / Windows 系统托盘：点击先出「历史记录 / 设置」按钮组，再打开对应 beam 置顶窗口 |
| Rust 业务核心 | 对话状态、模型接口、事件消费、配置与加密数据接口 | 平台路径、文件锁、文件权限、设备与进程能力经适配层处理；不得直接跨平台复用 Unix 专用调用 |
| 系统适配层 | 统一能力接口与能力探测 | 全局热键（尤其左右 Ctrl/Option 区分）、Esc 取消、麦克风与播放、系统 TTS、输入框写入、默认浏览器打开、权限与自启动分别实现 |

非激活浮层、透明背景、置顶、多屏与全屏应用上方可见性先做技术验证，不能假定所有 Tauri 窗口选项在两端等价。macOS 透明窗口可能涉及私有 API 或分发限制，实施前核查所选版本配置与签名/公证影响；如需额外原生插件，限制在平台适配层并记录原因。听写与通知默认不抢焦点，历史记录和设置需可正常获得键盘输入。锁屏、睡眠、取消、音频设备变化与退出释放均需覆盖。

## Node.js 过渡与数据安全

Rust 尚未补齐的 ASR/听写等能力，迁移期允许保留 Node.js 受管 sidecar（附带进程），不删除可用链路。sidecar 并非已打包可用：需为每个目标平台准备 Node 运行时、原生识别依赖与模型加载方案，并验证启动、IPC、取消、异常退出、资源释放及许可证。发布包不能要求用户手动安装 Node.js。Windows 原生依赖若不可用，则该阶段受阻，不能以壳能启动声称语音可用。

同一数据目录只能有一个有效写入者/事件消费者；新旧壳试运行使用隔离目录和合成数据，切换前备份并验证兼容，禁止双开宿主争用真实数据或重复通知。Rust 完整对齐且对应平台真机回归通过后，才移除 Node 依赖。旧版可回滚；迁移失败不重置配置、不覆盖真实运行数据。

Tauri capabilities/permissions 按窗口最小授权，IPC 参数后端校验；不向网页暴露通用 Shell、任意文件读写或任意外部 URL 执行。语音浏览器指令仅明确的 HTTP/HTTPS，系统权限由用户正常授权，不自动授予。密钥不传给视觉层、不记录日志。
