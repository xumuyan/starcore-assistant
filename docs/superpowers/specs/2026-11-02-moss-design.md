# MOSS 任务中间站设计

用户于 2026-11-02 明确批准开始实施；本文件归档已确认的范围，不新增审批环节。

MOSS 是可聊天的 Codex 任务中间站，主导航为任务、聊天、设置。替换默认全屏星球界面，保留原始场景资源；玻璃材质用于导航、工具栏和卡片，正文清晰优先。Mac 继续使用 AppKit/WKWebView，不引入 Compose。

任务：自动汇总本机所有非子代理、未归档 Codex 聊天的可靠状态，按聊天标识区分，同项目多聊天不合并。只读数据库与运行记录；开始、结束、异常使用明确事件，不根据文件变化猜进度。断连或证据不足显示未知，不虚构等待审批或百分比。复用已有完成通知去重和可选微信通道，不重发历史。

聊天：保留云桥文字/语音聊天与加密历史，显示当前固定目标。普通对话不执行；明确“让 Codex…”及“把刚才的方案交给 Codex 实现”才附近期上下文提交原聊天。先显示并固定目标，不随最新提醒悄悄换目标；没有目标或任务内容含糊则提示选择，不误投。仍遵循 Codex 本身权限。

听写：独立默认关闭，右 Option/F8/F9、本地识别、原输入框写入，不自动发送，即使听写内容包含 Codex 也不执行。

宠物：独立可关闭的轻量桌面形象，显示运行任务数量和真实状态；点击弹出轻量聊天，展开到主聊天页；共用任务快照及原聊天后端，不创建第二个助理或记录体系。

命名：面向用户的当前应用、默认助理称呼与唤醒词统一 MOSS；只将内置旧默认“贾维斯”迁移为 MOSS，保留用户自定义称呼。bundle ID、私有数据路径、GitHub 地址继续保持，避免丢失授权或数据。历史文章保留历史事实。

后续仅预留小米音响提醒/聊天接入，不在本期实现 iPhone、音响控制或额外自动化平台。

验收：单元模拟与真实本机只读状态、界面、安装分别记录；权限/人声没有实际完成继续未验收。原微信会话不重绑，原数据不重置。
