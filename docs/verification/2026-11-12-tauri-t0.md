### 实际观察与限制

- 只读 CoreGraphics 查询发现默认 chooser 已在屏幕内，layer 5、alpha 1、sharingState 1，280×100；桌面工具仍列出 0 个 probe 窗口。证实“未列出”不等于“未显示”，不能断言浮动层是唯一原因。
- 新增显式 `--diagnostic-controls`：三个控制页变为普通层、带标题栏、不透明窗口，macOS 使用 Regular 激活策略并显示 chooser；默认不启用、不持久化。overlay 的透明置顶/不聚焦/鼠标穿透配置不变。标题标记 diagnostic，增加诊断标题栏空间；不是正式布局修改。
- 临时 bundle 的普通控制模式被工具列出；经工具正常应用激活后取得 chooser 单窗截图。Tab 动作后截图出现“历史记录”按钮焦点环，记录为有限键盘导航观察，不是输入框或 IPC 验收。
- 点击尝试被工具以“目标窗口或输入焦点无法确认/已经变化”中止；另一事务回车后未观察到页面切换，后续输入也因焦点变化停止。未绕过保护、未使用其他注入路径。未证明按钮命令成功、热键可用或 overlay 不抢焦点；不因诊断窗口可列出就解除整个阻碍。
- 以上为本机 debug 工程的有限观察；随后加入标题标记和额外标题栏空间，仅构建/测试，不额外声称该最终布局已现场验收。过程截图和原生采样仅临时保存、不提交桌面或进程原始数据；测试进程已关闭，无长期启动项。

### 用户可执行的手工流程（结果待反馈）

只运行隔离 probe，不替换已安装 MOSS，不授权新权限，不输入真实聊天/密码。可先用普通模式核对 IPC，再退出用默认模式验证目标窗口行为；两者证据分开记录。

1. `npm run desktop:probe -- -- --diagnostic-controls`。点击“历史记录”，应显示未接入声明，不应出现真实记录；从菜单栏图标重新打开按钮组，再进“设置”。确认无动作失败提示，并在输入框键入合成字符串 `T0-input-123`，不应保存到下次启动。
2. 在设置依次选择四个效果。记录 voice-ring 收音/思考/回复、orbs 听写思考是否显示；按 Esc 应隐藏浮层，设置页仍可输入。不要将固定电平误认作录音。
3. 勾选临时热键后，用 Cmd+Shift+F8 显示/隐藏合成浮层；在其他应用的空白测试输入框保持键盘焦点，再按热键，继续键入合成文字，检查原焦点是否保持；点击浮层覆盖区域的测试按钮，检查鼠标穿透。出现冲突提示时记录失败，不改系统热键设置。
4. Esc 隐藏后检查其在原应用恢复正常；取消临时热键勾选后应不再触发。退出验证壳，再重新启动，应热键关闭、输入框为空且无浮层。CLI dev 请同时终止开发进程；不要把 CLI 常驻误记为退出资源泄漏。
5. 普通模式退出后，运行 `npm run desktop:probe`：应只有独立图标，点击先显示按钮组，再选择页面。重复输入、overlay 焦点/穿透、热键/Esc 测试；这一步才涉及目标透明置顶控制页。诊断模式成功不能替代此步。
6. 分别在双屏、全屏应用、Spaces 切换以及睡眠/恢复后检查窗口位置、可见性、焦点和热键释放；记录具体环境与失败项。不要在锁屏界面或私人输入框测试。

反馈建议：逐项记录“通过 / 失败 / 未测”，注明普通诊断模式或默认模式。仅可确认的项目补证据；T0 清单、精确视觉/动画与 Windows 仍保持未勾选。


## SC-20261112-008 原生合成 IPC 自检

状态：**T0 仍未验收**；本批为实际 WKWebView 合成集成检查，不是桌面输入安全限制的绕过，不包含键盘/鼠标注入，不自动操作其他应用。普通产品入口、已安装副本、配置/历史、权限保持不变；T1 业务服务未接入。

### 路径及实际结果

- 新增显式 `--self-check`，只在默认透明/置顶窗口配置中执行；与普通诊断模式或 show-chooser 同用在创建窗口前拒绝。正常启动不加载自检流程，后端四个自检命令也会拒绝；只增加 AppManifest 中的有限命令，不开放 Shell/文件/网络权限。
- 四个页面在本地事件订阅和 snapshot 完成后向 Rust 报就绪；只有 chooser 能请求检查/结束，只有 overlay 能确认渲染，调用身份由 Tauri 注入而非网页参数提供。检查点强制顺序且不可提前通过。自检有 20 秒 watchdog，runner 有 30 秒/64 KiB 输出上限，验证全部固定检查点、成功标记及退出码，不打印原始进程日志。
- 实际运行 `npm run check:desktop:native` 的固定结果如下（仅合成标签，不含桌面截图或私人数据）：

```text
T0_CHECKPOINT Boot
T0_CHECKPOINT Bounded
T0_CHECKPOINT History
T0_CHECKPOINT Settings
T0_CHECKPOINT Listening
T0_CHECKPOINT Processing
T0_CHECKPOINT Speaking
T0_CHECKPOINT Dictation
T0_CHECKPOINT Hidden
T0_SELF_CHECK PASS
```

- Boot 检查四窗初始隐藏、热键关闭、Esc 未注册及页面全部就绪；Bounded 前实际 IPC 拒绝非法 Page/Demo/Step 枚举和 chooser 冒充 overlay 的确认请求。
- History/Settings 检查通过实际网页 invoke 打开对应窗口、chooser 隐藏；不是物理按钮点击成功，也没有真实输入框键入。历史页仍只是未接入声明。
- Listening/Processing/Speaking/Dictation 检查 Rust 状态、窗口 visible、插件 Esc 注册表，以及 overlay 经真实事件更新后提交的自身 React DOM、对应 phase 与 Canvas 存在；没有核对像素、帧率或 GPU 绘制质量。不是参考动效逐帧验收。
- Hidden 检查 demo 清空、overlay 不可见、效果节点卸载和 Esc 插件注册表为空；结束再次清理后退出码 0。Cmd/Ctrl+Shift+F8 始终未启用；注册表状态不能代表物理 Esc 派发或系统其他应用恢复行为已验收。
- 首次原生运行在 Dictation 后失败、未完成 Hidden；当时在 requestAnimationFrame 中确认卸载，隐藏 WebView 可能暂停该回调。改为 React 提交后的 useEffect 直接检查自身 DOM，再运行完整九点及退出均通过，并新增“隐藏确认不依赖动画帧”测试。没有通过延长超时或跳过隐藏检查来掩盖失败。
- 最终原生自检重复执行与互斥参数拒绝结果、完整回归/两类构建及 Rust 测试结果见操作日志。原生自检不在 npm test 中自动运行，需显式执行；runner 没有构建/安装默认产品的行为。
