# SC-20261115-020/021 单实例数据安全与接线链路组合汇总

汇总两批默认关闭离线工作的已验证边界、生产差距与不可推断事实。详见 [SC-20261115-020 单实例模型](2026-11-15-single-instance-model.md) 与 [SC-20261115-021 链路组合](2026-11-15-wiring-chain.md)；口径对齐 [SC-20261115-019 复查/时机模型](2026-11-15-wiring-recheck-timing-models.md)。不接真实 UI、剪贴板、输入注入、系统监听、文件系统、进程、timer 或生产接线；不改生产源码与默认关闭行为。权限一律走 macOS 用户正常授权流程，不自动授予。

## 一、已验证边界（离线模型/组合，默认关闭）

1. **单实例互斥认领**（SC-20261115-020）：同一时刻至多一个 live claim；非持有者 release 被拒不改状态；自愿释放后槽位可再认领。
2. **重复启动 fail-closed**（020）：第二次 claim 记 duplicate-startup，永久锁存置 contended、触发 onFail；锁存后全部入口拒绝，无重置。
3. **退役不可逆**（020）：retired 后任何实例（含原 ID）永不能再认领，不存在 unretire；非持有者 retire 被拒不改状态。
4. **数据白名单**（020）：写请求仅 `(path, kind)` 对且 API 无内容参数；仅 kind='encrypted-record' 且路径精确匹配既有加密记录白名单才接受；前缀/后缀/未知路径与 plaintext 一律拒绝；retired/latched/unknown-path/plaintext-or-invalid/disabled verdict 可区分。
5. **跨组件身份/回执/截止一致**（SC-20261115-021）：链路共享单一逻辑时钟，每业务入口先过期限门控；ack 协议 job id 即控制器 prepare 的 UUID；协议 display 与控制器快照一致；executor 复查证据 observedAt 与门控同刻。
6. **任一环失效整链 fail-closed**（021）：期限到期关门控且 executor dispatch/prepare 被拒；复查拒绝定 not-written 且 written 报告被拒；mid-flight expire 锁 unknown 不可升级；supersede 后迟到回执锁死协议、后续 sendPrepare 以 protocol-failed 拒绝。
7. **旧帧/旧回执不穿越新一代**（021）：suspend→resume 不复活须显式 rebuild；新代 token 与旧代不同；旧 epoch envelope 不能同步新代控制器。

## 二、生产差距（未实现、未验收）

1. 真实单实例机制：flock/lockfile 原子性、崩溃后陈旧锁回收、多用户场景未实现；模型 claim 是纯逻辑，不是进程间互斥证明。
2. 真实加密记录存储对接：白名单由调用方构造时提供，模型不验证磁盘文件真实存在或确为加密内容；崩溃恢复与锁存重置策略未设计验收。
3. 真实链路：链路组装逻辑只存在于测试 harness（不是生产代码）；真实 IPC 通道与回执传输、真实子进程启动时机、真实期限源（时钟、锁屏监听）、真实执行器边界复查均未实现。
4. 生产 TOCTOU 窗口只能缩小、不能声明消除；权限检测与未授权 fail-closed 未实现。

## 三、不可推断事实与反例

1. **不能从 claim 通过推断系统级单实例成立**：两个真实进程可各自构造 enabled 模型并 claim 成功。
2. **不能从白名单接受推断磁盘写入安全**：模型只检查 (path, kind)，不执行任何 IO；API 无内容参数也不证明调用方不会用其他 API 写明文。
3. **不能从 retire 推断真实进程已退出**：退役是逻辑状态，进程回收属 OS。
4. **不能从组合测试通过推断生产链路成立**：四个模型互不知晓，组合逻辑仅在测试内。
5. **不能从 ack id 一致推断回执认证安全**：单消费者 token 是测试内注册的本地假设。
6. **不能从门控拒绝推断业务组件自带同样守卫**：期限门控是测试内叠加的链路规则，executor 模型另有自己的 TTL。
7. **不能从专项/回归全绿推断验收完成**：SC021 整批、T0、T1、G1～G6 仍未验收；SC-20261115-020 专项 7/7、SC-20261115-021 专项 4/4、完整回归 922/922 均为离线验证结果，不是真机或生产验收。
