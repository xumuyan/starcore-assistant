  ```sh
  app='/Applications/MOSS T0 Probe.app'
  plutil -extract CFBundleIdentifier raw "$app/Contents/Info.plist" &&
    plutil -extract CFBundleExecutable raw "$app/Contents/Info.plist" &&
    codesign --verify --deep --strict "$app" &&
    shasum -a 256 "$app/Contents/MacOS/moss-desktop-probe"
  ```

  预期 ID `dev.starcore.moss.t0-probe`，可执行文件 `moss-desktop-probe`；本机 ad-hoc 签名不等于 Developer ID 或公证。若使用单独构建的隔离临时 bundle，对其实际路径执行相同核对、启动并记录，不覆盖已安装副本。

- 每次只运行一份、不要并行运行两种模式；启动后按 bundle ID、PID 和实际可执行路径确认是本次探针。`open -a … --args` 不应用于更改已运行探针的模式，须先退出并确认实例已结束。只测独立的 **MOSS T0 Probe**，不碰沐言、旧服务、真实配置或历史，不为本次测试授权新权限，不修改系统热键。
