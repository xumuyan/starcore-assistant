## 开始前

- 在仓库根目录终端执行命令。复用现有依赖，不需重新安装。先保存手头工作，避免在重要输入/快捷键操作期间测试。
- 只测试独立的 **MOSS T0 Probe**，不是现用 MOSS。不要替换已安装应用，不修改真实配置、历史或系统热键，不为本次测试授权新权限；出现权限申请先取消并反馈。
- 页面只含合成效果，没有录音、识别、聊天或真实历史。不要在密码框、终端命令行、真实聊天/业务表单测试输入或穿透。使用临时空白文本或本地测试页面，只输入 `T0-input-123` 等合成文字，不按发送。
- 窗口标题含 `diagnostic` 的是普通诊断页，**不能替代默认透明置顶模式验收**。两种模式分别填写。
- 临时热键默认关闭；只有你手动勾选才启用 Cmd+Shift+F8（Windows 声明为 Ctrl+Shift+F8，本单不证明 Windows 可用）。若 F8 是媒体键，可按键盘正常方式使用 Fn；不要改系统键位。Esc 仅浮层显示时注册，结束应释放。出现动作失败/冲突就记录失败，不反复触发或改系统设置。
- 如终端找不到 node/npm，用本机现有 Node 环境；本次开发机可先执行 `export PATH="$HOME/.nvm/versions/node/v22.22.0/bin:$HOME/.cargo/bin:$PATH"`。其他机器不要照抄版本路径。
