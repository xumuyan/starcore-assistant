## 实际边界

这是加密落盘与本账户免反复授权，不是依靠独立密码或硬件隔离的加密箱。已控制该 Mac 账户的程序可读取本地解密密钥。备份需同时保留 master.key 和加密文件；不能丢失或单独删除它。

变更只覆盖本客户端密钥、设置、聊天及 Mac 交接正文；原 Codex 会话、微信 SDK 账号、既有通知队列、系统快照和外部备份仍遵循各自存储规则。没有声称抹除了外部旧副本。

图片是生成的场景美术，叠加代码动效；尚不是实时三维场景。原聊天的新语音开发要求到执行完成、微信收取的整条链路仍需用户按实际项目验收。iPhone、小爱音箱、语音抢话和跨设备同步仍在后续范围。
