# 0.6.0 原图保真验收

日期：2026-10-30。根据用户再次指出的参考图差异，本轮用原始场景素材替代 0.5.x 的近似几何重建，校准字幕、标志、控制条与侧栏。

## 视觉与动态

主体为已选定生成图的原始无文字场景。透视相机渲染推断深度场，在默认视角保持原图构图；近景与远景投影倍率不同。细节动画包含轻微核心光流、原底盘扫光、微小星球漂移/表面移动、星点闪烁与独立三维光点。方案为 2.5D，并非可任意环绕的完整机械三维模型。

同尺寸整体及局部比较保存在 `docs/qa/reference-comparison-v6.jpg`；所选真值 `reference-target-v6.png`、实际欢迎画面 `reference-ui-v6.jpg`。对照样例模拟聆听，不采集麦克风、不调用模型，不代表真实语音录音验收。源图与实际画面均为 1672×941，截图 JPEG 压缩和生成图字体本身带来的微小差异已记录。详细检查见项目根目录 `design-qa.md`（passed）。

控制条实际测量为 x=621、y=806.125、430×68 px。浏览器日志未见警告或错误；动态图形验收为 PASSED，五项光流/粒子时间均变化，减少动态后全部冻结，镜头 6.1 → 5.0503 → 6.0999。实际场景绘制调用数为 2。目标 30 FPS，但不对所有设备承诺帧率。
