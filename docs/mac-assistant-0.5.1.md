# 0.5.1 动态场景验收

日期：2026-10-30。依据本轮用户反馈修正中心区域，并让底盘、星球、星点独立运动。

## 实现

- 中央内核球体半径由 .98 降到 .70，增加一层反向机械环及分段合金面板，减弱外网格和大面积光晕。
- 环境 v5 清除画死的底盘、星球和亮星点，保留房间、地面及空间线条；旧版本素材仍保留。
- 底盘使用水平三维平面、解析抗锯齿环线、两层反向旋转弧段、扫光、光点及轻微光感变化。整体几何不随音量缩放。
- 四颗行星为实时球面，表面光照、纹理随自转改变，位置缓慢绕行；1100 个不同深度星点分别漂移、闪烁。
- 背景与核心共用同一动画时间，隐藏时暂停，减少动态时一起冻结。保留原有透视缩放、音量响应和静态备用。
- 后期输出与 Canvas 均使用预乘透明度，避免暗部细轨道重复乘透明度以及 WKWebView 中蓝色光晕变为实心色块。

## 验证

42 项 Node 测试通过，其中新增背景多层运动与冻结、固定底盘尺寸、窗口变化后的星球可见范围及场景对象数量检查。

真实 WebGL 页面验证：核心、底盘环、扫光、星点时间和星球转角均持续改变；减少动态后五项均保持不变；镜头推进到 5.0502，退回 6.0999。当前场景约 225 次绘制调用（含后期处理），图形日志未见警告和错误。不以此承诺所有设备均达到 30 FPS。

已保存七秒实际渲染演示：`docs/qa/jarvis-living-scene.mp4`，包含底盘、行星、星点和相机推进/退回。它来自独立本地验收页，不采集真实语音、不调用聊天或 Fish 接口。

Mac 客户端已构建并安装为 0.5.1 / build 9、arm64，本地签名严格校验通过。原生 WKWebView 已显示新的机械环、动态底盘和四颗星球，透明蓝色光晕色块问题已修正；实际截图保存为 `docs/qa/jarvis-living-native.jpg`。仅更新客户端 UI，未改后台运行副本、模型配置、加密库、密钥或聊天投递。保留原有麦克风 API 在 macOS 27 SDK 下的弃用警告，编译成功。

素材及内置 imagegen 完整提示词见 `docs/design/living-scene-imagegen-prompt.md`，实现范围见 `docs/design/2026-10-30-living-scene.md`。
