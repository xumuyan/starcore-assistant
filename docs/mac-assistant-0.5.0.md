# 0.5.0 实时三维核心验收

日期：2026-10-30。用户指出此前画面主要以背景呼吸代替空间运动，本次沿用既定参考构图并修正实现。

## 变化

环境背景和核心分离。核心由 Three.js 0.186.1、真实透视相机、球面纹理材质、轨道几何、刻度、光丝和三维粒子构成；各轨道沿独立轴和速度旋转。查看核心、返回全景和滚轮缩放改变相机位置，不缩放 HTML 页面或整张背景。

球面细节是生成纹理，投射到真实三维球体上；轨道并非画在纹理上的环。动态几何与参考的单张生成图存在外观差异，未声称逐像素复现或完整重建环境三维模型。

麦克风保持真实采集电平；Fish 播放通过 AVAudioPlayer metering 每 50 ms 采样，单独驱动 outputLevel。系统声音没有伪造的播放电平。减少动态停止自动旋转和音量驱动的相机移动。

## 验证

- 40 项 Node 检查通过，包含原有聊天、加密、微信和原聊天投递回归，以及新增的相机连续性、透视深度差异、输入/输出电平分离和减少动态检查。
- 浏览器预览运行真实 WebGL，读取的相机距离从 6.1 平滑到 5.05，连续帧中轨道角度变化；前后深度投影倍率不同。
- 通过明确 DOM 控件验证 reduced=true 后轨道角度保持不变，再恢复运动。视觉验收页不调用模型，也不采集真实麦克风。
- 已录制 3.25 秒实际渲染的相机推进和退回演示：`docs/qa/jarvis-3d-motion.mp4`，另有 WebM。包含本地演示标识，不是合成的未来效果图。
- Mac 原生 WKWebView 已检查，实际显示新的球面和轨道，未进入静态备用模式。客户端版本 0.5.0 / build 7，arm64，本机签名校验通过。
- 本次未改模型服务、加密方案、密钥、聊天记录或任务投递；不需要重新配置，也未重启 Codex 或微信后台。

## 素材与打包

imagegen 环境图：`client/hud/environment-v4.png`；球面纹理：`client/assets/PlasmaSurface-v4.png`。完整提示词：`docs/design/core-v4-imagegen-prompts.md`。

Three.js 与 esbuild 使用固定版本。客户端仅加载随包附带的脚本和内嵌纹理，不从 CDN 取脚本或纹理；Three.js MIT 许可随应用保留。绘制目标约 30 FPS，限制渲染像素比例；这不是所有设备下的帧率保证。

Fish 电平采样已接入原生播放代码并构建。本次视觉检查使用明确标识的模拟音量，不为动效验收额外调用 Fish/聊天接口；日常声学体验仍以用户实际播放和反馈为准。
