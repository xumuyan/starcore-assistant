# 中央球体接缝与光效 · 0.6.3 / build 13

## 根因与修复

核心网格会绕 X 轴轻微倾斜，而相邻球壳只在平面内旋转。两者使用相同半径的分割边界，却不再共享同一投影边缘。在 5.6 秒和 16.8 秒复现约 0.892 个参考像素的空隙；穿过该位置的射线未命中任何原球体网格，露出后方暗环境。

补充一张连续的原图投影曲面，后移 0.04 世界单位，覆盖所有分层边界后的空隙，同时避免共面闪烁。核心与球壳显示开关通过遮罩同步；不靠黑色描边或更强光晕掩盖缝隙。新增回归测试保留原有倾斜，断言射线穿过旧分层后仍命中连续底层。

## 新增效果

新增 160 个蓝色为主、少量暖色的局部光粒子，两条反向短光轨。效果位于核心附近，沿实际三维位置运动，不改变主相机、球体整体 scale 或主轮廓。真实语音能量可以小幅增加亮度。图形时间均由既有时钟传入，没有额外自主动画循环；暂停、后台和减少动态保持一致。线框模式隐藏光效。
