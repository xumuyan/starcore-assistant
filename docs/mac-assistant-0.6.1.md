# Mac 助理 0.6.1 / build 11

## 代码

从已验收的 v3 独立样片提取共享 `client/scene/projected-scene.mjs`，样片重导出该模块；正式 renderer 复用实际曲面网格和原图 UV。保留原生应用的真实语音/聊天桥接、名称、唤醒词、设置、项目、历史及加密存储。

正式镜头固定，不再使用指针、滚轮或输入音量改变相机。真实麦克风/播报音量经既有包络平滑后影响核心亮度；停止音频、关闭麦克风会清理输入。减少动态冻结时间，页面隐藏暂停绘制。静态备用画面与状态提示保留。

所有场景图片以 data URL 随脚本内嵌，修复原生 WKWebView 中 file 来源纹理加载触发回退的问题。设置增加动态运行/暂停/回退状态，便于核验。

## 构建与安装

版本 0.6.1，build 11，Apple Silicon arm64，ad-hoc 签名；codesign --verify --deep --strict 通过。保留原 bundle identifier。构建使用 --ui-only --no-install，未更新 Node 运行副本，再验证后替换应用。

安装：`~/Applications/Codex 微信提醒.app`。
回退包：仓库 `dist/backups/Codex 微信提醒-0.6.0-10.app`。退出新助理后复制该包回原安装位置即可恢复，数据保存在原有独立目录，勿删除或覆盖数据目录。

旧助理在语音未开启、空闲状态退出；未退出 Codex 或微信。新助理已经打开。设置和数据目录未手动改写，原生设置中确认已有密钥显示加密保存，主页恢复原有聊天。未记录任何密钥、聊天原文或历史截图作为 QA 文件。

## 验证

- 完整 Node 测试：47/47。
- 生产页面模拟事件：播报能量约 0.76，打断后约 0.003；cameraLocked=true、scale=[1,1,1]、减少动态后时间冻结。
- 浏览器生产渲染器日志：无 warn/error。
- 原生 WKWebView：设置显示“动态效果正在运行”，没有进入静态回退；加密密钥状态恢复，文字输入可打开并退出。
- 构建存在原有 AVAudioEngine.installTap 的 macOS SDK 弃用警告，未阻断构建和签名。
